ABSTRACT 
The project proposes a type of Artificial Neural Network (ANN) known as Long Short Term Memory 
(LSTM) to predict the prices for a portfolio of best stocks from five different sectors since election. 
The current price, technical and fundamental indicators will be learned to predict the next day’s price. 
The LSTM model will modulate and internally optimize the prices based on certain rules. By 
comparing the actual and predicted prices, the network provides trading signals which will then be 
used to back-test the data on a reliable platform. Later, we compare the back-testing results to measure 
the performance and risk metrics for two types of investors – risk-averse and risk-seeking. The main 
purpose of this project is to develop a system which either performs on par or outperforms the market.

INTRODUCTION 
 
Recurrent Neural Network 
In this project, we will be using Recurrent Neural Network (RNN) for time series analysis. Recurrent 
Neural Network (RNN) is a type of supervised deep learning which is specifically used for analysing 
time series. Unlike other neural networks, here, the information is dependent on each other. It consists 
of an internal memory, used to process various sequence of inputs. There are three layers in this 
network namely, the input layer, hidden or feedback layer and output layer. The hidden layer or output 
layer not only gives an output but also feeds in itself, which is the feedback is given from the output 
to the hidden layer. The only problem with this network is the vanishing gradient wherein a layer is 
created every time an input sequence is processed by the network. 
 
Long Short Term Memory 
Long Short Term Memory (LSTM) eliminates the vanishing gradient problem with its ability to learn 
with many non-linear layers. It consists of memory cells or memory pipeline which flows freely 
through time. The figure below consists of a diagrammatical representation of LSTM. Ct and Ct-1 are 
Electronic copy available at: https://ssrn.com/abstract=3889600

the memory cells for the given and previous modules through which memory flows. ht and ht-1 are the 
outputs from the given and previous modules. Xt is the input of the given module. There are two 
valves – x (allows the memory to flow freely when opened and cuts off supply when it is closed) and 
+ (also called as T-shaped valve which controls adding and updating new memory into the module). 
Finally, there are two activation functions called sigmoid and tan symbolized by σ and tanh 
respectively.

BUILDING THE NETWORK 
 
The idea for predicting time series data comes from the paper - A. Bernal, S. Fok & R. Pidaparthi 
(2012), Financial Market Time Series Prediction with Recurrent Neural Networks. The authors claim 
to have applied a type of RNN called Echo State Network (ESN) to predict the stock prices of S&P 
500. To test if this idea is valid, we will use LSTM to replicate the results from the paper. The reason 
for choosing LSTM over ESN is because it is more efficient and robust in addition to the many 
features of LSTM mentioned in the previous sections. For the sake of simplicity, the data we will be 
using is Google stock prices. The training period will be from 2012 to 2016 and the test period will 
be the first 20 days of January 2017. Later we will compare our results with that of the paper.

Architecture of RNN 
The Sequential( ) function is responsible for initializing the RNN as a sequence of layers. The 
regressor.add( ) function adds an input layer and LSTM layer. Within the LSTM( ) function, we have 
units equal to 4 (parameters tuning) and input shape which consists of the number of time steps and 
features. The Dense( ) function consists the dimension of the output stock price which is 1. For 
compiling the RNN, we use the optimizer ‘adam’ as it is more efficient and faster. The loss is 
measured in terms of mean squared error or MSE which acts as an optimizer by reducing the weights 
and updating itself. Later, we fit the RNN to the training set. The epochs within the regressor.fit( ) 
function are the sub-periods or iterations that learning takes to fit the inputs to the outputs. 
# Initialising the RNN

Model A (Price Model) 
Price model will be used to predict the stock’s price for the next time step. This model will be 
trained with supervised learning algorithms using historical price data. While predicting the 
next time step’s price is useful, it does not give an indicator as to what action a trader must 
take. A simple strategy would be BUY when the next time step’s price is greater than the 
previous time step’s price and SELL if it is not. A better strategy would be to provide these 
predictions to another model which decides the actions for us. This will be carried out using 
Model B or Decision model. 
 
Model B (Decision Model) 
To train the decision model, we will be using reinforcement learning where the agent can learn 
the optimal action by interacting with the environment. Supervised learning is not used because 
it does not seem possible to know the correct action to take at any given state. For this purpose, 
we will use Quantopian’s zipline back-testing to simulate the environment as it provides 
realistic conditions for our agent to learn the actions. The next state which is returned is then 
added to the model’s next day price, the current capital of the trader and the three features 
(fundamental and technical indicators, prices). 
The AI trader’s goal is to optimize a policy that allows it to accumulate maximum reward 
possible through the trading period. Therefore, the optimization problem would be to maximize 
the profits by varying the reward. The reward is the difference in the trader’s capital from today 
and tomorrow. 
Since the model has to be capable of learning long term dependencies as changes in the prices 
can be caused by an event several months or even years ago, we will be using LSTM to 
effectively model the market behaviour. The methodology was implemented in Python and the 
predictions for each day were used for back-testing on Quantopian. 
 
IMPLEMENTATION OF STRATEGIES 
 
It required close interaction with the back-testing unit to implement the decision model. Here, 
we will be using a simple rule based decision model. The strategy adopted whilst back-testing 
depends on the risk appetite of the trader. We will be testing a risk-seeking and risk-averse 
strategy for the portfolio of five stocks for three quarters between January and September 2017. 
In the risk-averse strategy, the decision for the trader will be BUY only if the change in the 
stock price is positive and hold if it is negative. Conversely, for a risk-seeking strategy, the 
decision for the trader will be BUY if the change in the stock price is positive or if the change 
in the stock price is negative and within a certain threshold. When the change in the price goes 
beyond the threshold, the position will be to hold. Following is the code which executes the 
trades for back-testing,

When we look at the above performance and risk metrics, both strategies seem profitable. The 
returns (annual and cumulative) for the risk-seeking investor is higher compared to the riskaverse investor. The volatility, skewness and kurtosis (peakedness) are also comparatively 
higher owing to the investor’s risk appetite. The ratios (Sharpe, Calmar, Omega, Sortino, Tail)

the risk adjusted returns. All the ratios signify that the risk-seeking strategy gives higher risk

Another thing to observe is that the alpha and beta is higher for the risk-seeking strategy. 
Though a higher alpha means a higher relative performance to the market, a higher beta shows 
that the strategy is more sensitive to the market changes when compared to the risk-averse 
strategy, as the lower beta of the latter almost guarantees market neutrality. 
Some of the reasons for this performance might be due to the strategies being high frequency 
(more trades within lesser intervals), frequent rebalancing of the portfolio and lesser correlation 
between the stocks and the back-testing period might have been prone to macroeconomic

CONCLUSION 
Predicting prices has been successfully implemented using LSTM. Though, there is a chance 
that the next day’s predicted prices has a look ahead bias but this is only the case  if you use 
one feature, the previous day’s price. In our case, we have used three features including the 
prices, daily technical and fundamental indicators. Later, we compared the predicted prices 
with the actual prices and came up with the trading decisions or actions for each day. These 
decisions were based on two strategies depending on the risk appetite of the investor (riskElectronic copy available at: https://ssrn.com/abstract=3889600

averse/risk-seeking). When these decision were back-tested on Quantopian, we got the 
performance and risk metrics as well as the returns and volatility plots for the overall trading 
period. Thus, LSTM gave us decent results as a trading and optimization tool. However, there 
are certain areas of improvements in ways that the model could use a larger dataset for training 
as this would allow us for a more complicated model and avoid over-fitting. Another area to 
improve on would be the decision model so that the decisions are more tuned with the market 
data.
