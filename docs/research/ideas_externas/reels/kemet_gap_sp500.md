## Resumen Ejecutivo

Este reel es puro data-driven, sin venta de curso. Es el estudio más limpio que viste hasta ahora: **670 días de gaps ES desde 2024 hasta hoy (2026)**.

**Regla central:** No todos los gaps se cierran. Depende del TAMAÑO.
- **Gap <10 puntos:** Cierra **9 de cada 10 veces (90%)** - Cuenta con que vuelva
- **Gap 20+ puntos:** Cierra **solo 1 de cada 3 (33%)** - 2 de cada 3 NO vuelve
- **Si a la 1 hora sigue abierto (10:30):** Solo **1 de cada 4 (25%)** se cierra después - Deja de esperarlo
- **Definición gap:** Apertura hoy vs Cierre ayer. Si abre 20 puntos o más lejos del cierre de ayer, 2 de 3 veces no vuelve a ese nivel en el día.

## Regla Decodificada para EdgeLab

**Nombre:** Kemet Gap Filter - ES Gap Size + Time Decay

**Definición Formal:**
```python
# edgelab/filters/gap/kemet_gap.py
gap = open_today - close_yesterday  # en puntos ES
gap_abs = abs(gap)
def gap_rule(gap_abs, time_ny, gap_closed):
    if gap_abs < 10:
        return {'action': 'EXPECT_FILL', 'prob_fill': 0.90, 'strategy': 'mean_reversion_to_yesterday_close'}
    if gap_abs >= 20:
        if time_ny < '10:30' and not gap_closed:
            return {'action': 'WAIT_1H', 'prob_fill_total': 0.33}
        if time_ny >= '10:30' and not gap_closed:
            return {'action': 'STOP_WAITING', 'prob_fill_after': 0.25, 'strategy': 'trend_follow_gap_direction'}
        return {'action': 'DO_NOT_EXPECT_FILL', 'prob_fill': 0.33}
    # 10-20 zona gris no cubierta en video - interpolar 60-70%?
    return {'action': 'GREY_ZONE_10_20', 'prob_fill': 0.60}
```

**Tabla Probabilidades:**
| Tamaño Gap ES | Prob Cierre Mismo Día | Acción |
| --- | --- | --- |
| <10 puntos | 90% (9/10) | Esperar fill, trade mean reversion hacia cierre ayer |
| 10-20 puntos | ~60-70% (no dado, interpolado) | Zona gris, esperar 1h |
| 20+ puntos | 33% (1/3) | No esperar fill, trade trend dirección gap |
| 20+ y sigue abierto a 10:30 (1h) | 25% (1/4) después | Deja de esperar, invalida setup fill |

**Tiempo:**
- Apertura ES: 9:30 NY (cash open) - gap medido a 9:30
- Deadline 1h: 10:30 NY = 60 min después open. Si no cerró en 60 min, prob cae de 33% a 25% condicional.
- Ejemplo 5 Ago: Tardó 108 min en cerrar (11:18) - outlier dentro del 25% que sí cierra después de 10:30.
- Ejemplo 2 Oct: Nunca cerró, mínimo quedó 28 puntos sin tocar cierre ayer.

**Dirección Después de Fill:**
- Gap fill NO predice dirección final del día. 5 Ago cerró gap a las 11:18 y luego cerró POR DEBAJO de cierre ayer (7,747.75 vs 7,764). Fill =/= bullish.
- Para EdgeLab: Gap fill es target, no señal direccional post-fill. Después de fill, necesitas otro filtro (VWAP, EMA, etc.)

## Estrategias Derivadas para EdgeLab

**1. Gap Fill Scalper (<10 pts):**
- Condición: Gap abs <10, hora <10:30
- Entry: Fade gap dirección, target cierre ayer, SL 5 pts beyond gap extremo
- TP: Cierre ayer, RR ~1:1 a 1:2, WR 90% teórico, EV positivo si costos < 10% win.
- Ejemplo: Gap +5 (VIE 28 AGO) - short a 7,746, target 7,741.25, 5 pts profit = $250 por contrato ES ($50/pt)

**2. Gap Trend Follower (20+ pts, no fill en 1h):**
- Condición: Gap abs >=20, hora >=10:30, gap sigue abierto
- Entry: Trend dirección gap, long si gap up, short si gap down, SL cierre ayer (20+ pts), TP 1:1 o VWAP NY
- WR 75% de que NO cierre después (1-25%), pero trend no garantiza profit, necesitas momentum filter (VWAP, EMA)
- Ejemplo: 2 OCT gap +63 - long a 9:30, target 7,789+? Cerró 7,779, +53 pts desde open? No, open 7,789.50 cerró 7,779 = -10 pts, trend up no profit si entras open. Mejor entrar pullback, no chase.

**3. Gap No-Trade Filter:**
- Si gap 20+ y hora <10:30, NO hacer mean reversion, NO fade gap, esperar.
- Si gap 20+ y hora >=10:30 y no cerró, NO esperar fill, cancelar órdenes limit a cierre ayer.
- Este filtro solo ya ahorra pérdidas de traders que siempre esperan fill.
