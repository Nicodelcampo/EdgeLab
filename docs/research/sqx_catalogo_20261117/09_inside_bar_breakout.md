## Reglas completas y parámetros por defecto

### Lógica exacta del `.sqx`
- Evaluado **al abrir cada vela** (`On Bar Open`), buscando compresión estricta de rango respecto a la vela madre previa (*Inside Bar*):
  - `High[1] < High[2] AND Low[1] > Low[2]`
- **Órdenes Stop OCO bidireccionales:**
  - **Buy Stop:** `High[1] + StopOffsetInPips` *(default `65` pips en `.sqx`, equivalente a `0.65 USD` en oro o ajustar a `0.15–0.25 * ATR(14)` por activo)*
  - **Sell Stop:** `Low[1] - StopOffsetInPips`
  - **Validez de ambas órdenes:** `BarsValid = 20` barras (`Replacing = allowed`).
- **Gestión de riesgo / salida:**
  - `StopLoss = 0.5 * BarRange[1]` *(donde `BarRange[1] = High[1] - Low[1]`; en EdgeLab añadir piso mínimo en ATR para asegurar que `SL >= 12x` costos ida/vuelta y no sea barrido por ruido mínimo)*
  - `ProfitTarget = 2.0 * BarRange[1]` *(ratio `4:1` geométrico)*
  - `Move SL to BE = 10 pips` *(recomendable parametrizar también como fracción de `ATR` o apagar en ablación)*
  - Activar `ExitOnFriday = 15:55 NY` al medir en EdgeLab.

### Pseudocódigo oficial (generado por SQX Build 145)
```text
//--------------------------------------------------------------------
// Pseudo Source Code of New strategy (InsideBarBreakout.sqx)
//   Generated by StrategyQuant X Build 145 for MetaTrader
//--------------------------------------------------------------------
int StopOffsetInPips = 65;
int BarsValid = 20;
int MagicLong = 11111;
int MagicShort = 22222;

Main chart = Current Symbol / Current TF;

// Trading rule: Rule 1 (On Bar Open)
if ((High(Main chart)[1] < High(Main chart)[2])
   and (Low(Main chart)[1] > Low(Main chart)[2]))
{
    // Action #1
    Open Long order at (High(Main chart)[1] + ConvertToRealPips("Current", StopOffsetInPips)) Stop;
        Order valid for BarsValid bars;
        Size = 0.1; Duplicate trades = disabled; Replacing pending orders: allowed;
        Stop Loss at ConvertToPips("Current", (0.5 * BarRange(Main chart)[1]));
        Profit target at ConvertToPips("Current", (2 * BarRange(Main chart)[1]));
        Move SL to BE = 10pips;

    // Action #2
    Open Short order at (Low(Main chart)[1] - ConvertToRealPips("Current", StopOffsetInPips)) Stop;
        Order valid for BarsValid bars;
        Size = 0.1; Duplicate trades = disabled; Replacing pending orders: allowed;
        Stop Loss at ConvertToPips("Current", (0.5 * BarRange(Main chart)[1]));
        Profit target at ConvertToPips("Current", (2 * BarRange(Main chart)[1]));
        Move SL to BE = 10pips;
}
```

## Mecanismo y cómo podría refutarse

- **Mecanismo:** Las barras interiores reflejan contracción transitoria de volatilidad e indecisión entre compradores y vendedores tras un movimiento previo. Colocar órdenes Stop a ambos lados con `R:R = 4:1` busca capturar la expansión direccional posterior cuando la volatilidad revierte a su media.
- **Cómo refutarse en EdgeLab:** Si en `GC`, `CL`, `FDAX` y `6E` (`H4`/`D1`): (1) la tasa de acierto cae por debajo del `20%` necesario por barridas repetidas del stop estrecho (`0.5 * BarRange`), especialmente si `MoveSL2BE = 10` corta ganadores antes de despegar; (2) la frecuencia de `Inside Bar` en `D1` o con offset alto deja `< 200` operaciones en `10` años.

## Hueco de diversificación

- **Sesión / Activo / Horizonte / Estilo:** Independiente de horario NY open, aplicable a **oro (`GC`), crudo (`CL`), `FDAX` y `6E`**, horizonte **1–5 días (`H4`/`D1`)**, estilo **ruptura OCO por compresión estructural de volatilidad**.
