## Reglas completas y parámetros por defecto

### Lógica exacta del `.sqx`
- Evaluado **al abrir cada vela** (`On Bar Open`), con máximo `1` posición (`MarketPosition is Flat`):
  - **Entrada Larga (extensible simétricamente con `-DI(20) crosses above 15` y `Highest(25)` para cortos en EdgeLab):**
    - `ADX(20).+DI[1] crosses above 15`
    - Entrada `Open Long at Market`.
- **Gestión de salida y riesgo (sin Profit Target fijo — deja correr tendencias):**
  - `StopLoss = 80 pips` *(adaptable a `1.5–2.0 * ATR` al probar multi-contrato)*
  - `Move SL to BE = 60 pips`
  - **Regla dinámica `Move SL To Low`:** en cada apertura de vela mientras el trade esté largo y en beneficio abierto (`Open PL in Pips > 0`), si `Lowest(Close, 25)[1] - 10 pips > OrderStopLoss`, sube el SL a `Lowest(Close, 25)[1] - 10 pips` (trailing estructural monotónico, nunca retrocede).
  - **Manejo fin de semana:** activar `ExitOnFriday` (`15:55 NY`) para EdgeLab o testear su costo vs hold semanal.

### Pseudocódigo oficial (generado por SQX Build 145)
```text
//--------------------------------------------------------------------
// Pseudo Source Code of New strategy (TrailingStopByLowest.sqx)
//   Generated by StrategyQuant X Build 145 for MetaTrader
//--------------------------------------------------------------------
double StopLossInPips = 80;
int BarsBack = 25;
int TrailingStopOffset = 10;
int MagicNumber = 10000;

Main chart = Current Symbol / Current TF;

// Trading rule: Go long (On Bar Open)
if ((MarketPosition("Any", MagicNumber, "") is Flat)
   and (ADX(Main chart,20).+DI[1] crosses above 15))
{
    Open Long order at Market;
        Size = 0.1;
        Duplicate trades = disabled;
        Stop Loss = StopLossInPips pips;
        Move SL to BE = 60pips;
}

// Trading rule: Move SL To Low (On Bar Open)
if (((MarketPosition("Any", MagicNumber, "") is Long)
   and (Open PL in Pips("Any", MagicNumber, 0, "") > 0))
   and ((Lowest(Main chart, BarsBack, PRICE_CLOSE)[1] - ConvertToRealPips("Current", TrailingStopOffset)) > OrderStopLoss("Any", MagicNumber, 0, "")))
{
    Move Stop Loss to (Lowest(Main chart, BarsBack, PRICE_CLOSE)[1] - ConvertToRealPips("Current", TrailingStopOffset))
      for every open order with Magic Number = MagicNumber;
}
```

### Export oficial a MQL5 (núcleo generado por SQX Build 145)
> Generado directamente por SQX Build 145 (`TrailingStopByLowest.mq5`):

```mql5
#property tester_indicator "SqADX"
#property tester_indicator "SqLowest"

input int    MagicNumber        = 10000;
input double mmLots             = 0.1;
double StopLossInPips           = 80;
int    BarsBack                 = 25;
int    TrailingStopOffset       = 10;

#define ADX_1    0  // iCustom(NULL,0, "SqADX", 20)
#define LOWEST_1 1  // iCustom(NULL,0, "SqLowest", BarsBack, PRICE_CLOSE)

void OnTick() {
   if(Bars(_Symbol,_Period) < minBars) return;
   if(CopyRates(_Symbol, _Period, 0, 2, mrate) < 2) return;
   checkBarOpen();
   sqManagePositions(MagicNumber);
   openingOrdersAllowed = sqHandleTradingOptions();

   ulong _ticket;
   double openPrice, sl, pt, size;

   // Rule: Go long
   if (_sqIsBarOpen == true
      && (sqMarketPositionIsFlat(MagicNumber, "Any", "")
      && indyCrossesAbove(ADX_1, "15", 1, 0, 1, 0)))
   {
      if(LongEnabled) {
         openPrice = SymbolInfoDouble(correctSymbol("Current"), SYMBOL_ASK);
         sl = sqFixMarketPrice(sqGetSLLevel("Current", ORDER_TYPE_BUY, openPrice, 1, StopLossInPips), "Current");
         pt = sqFixMarketPrice(0, "Current");
         size = 0.1;
         _ticket = openPosition(ORDER_TYPE_BUY, "Current", size, openPrice, sl, pt,
            correctSlippage(sqMaxEntrySlippage, "Current"), "", MagicNumber, ExpirationTime, false, false);
         if(_ticket > 0) {
            sqSetMoveSL2BE(_ticket, "60", SLPTTYPE_RANGE);
         }
      }
   }

   // Rule: Move SL To Low
   if (_sqIsBarOpen == true
      && ((sqMarketPositionIsLong(MagicNumber, "Any", "")
      && (NormalizeDouble((double) sqGetOpenPLInPips("Any", MagicNumber, 0, ""), 6) > 0))
      && (NormalizeDouble((double) (sqGetIndicatorValue(LOWEST_1, 0, 1) - sqConvertToRealPips("Current", TrailingStopOffset)), 6)
        > NormalizeDouble((double) sqGetOrderStopLoss("Any", MagicNumber, 0, ""), 6))))
   {
      int sqLoopIndex = sqPositionsLoopStart();
      while(sqSelectNextPosition(sqLoopIndex, MagicNumber, "Any", 1, "")) {
         sqSetSLPTByType(PositionGetInteger(POSITION_TICKET),
            (sqGetIndicatorValue(LOWEST_1, 0, 1) - sqConvertToRealPips("Current", TrailingStopOffset)),
            0, SLPTTYPE_LEVEL);
      }
   }
}
```

## Mecanismo y cómo podría refutarse

- **Mecanismo:** Cuando el componente alcista `+DI(20)` cruza desde compresión por encima de `15`, marca el despertar de presión compradora antes de que una EMA lenta reaccione. Combinar ese gatillo temprano con un trailing estructural por soporte (`Lowest 25`) sin techo de beneficio permite capturar extensiones tendenciales largas en energía/metales/FX manteniendo acotado el riesgo inicial.
- **Cómo refutarse en EdgeLab:** Si el gatillo `+DI > 15` resulta demasiado ruidoso en consolidaciones (disparando muchos stops de `80` pips antes de activar `BE` o `Lowest 25`), produciendo Win Rate `< 30%` con PF neto `< 1.0` tras comisiones y deslizamiento de futuros.
