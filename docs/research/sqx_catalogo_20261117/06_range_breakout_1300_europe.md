## Reglas completas y parámetros por defecto

### Lógica exacta del `.sqx`
- Evaluado **al abrir cada vela** (`On Bar Open`), cuando:
  - No hay posición ni órdenes pendientes activas (`MagicLong=11111`, `MagicShort=22222`).
  - La vela recién cerrada tiene hora exacta **`13:00`** (`RangeEndingHour = 13`, `RangeEndingMinute = 0`; equivalente en hora del servidor SQX `EST+07` a `06:00 NY`, finalizando la sesión asiática/mañana europea e inicio pleno de liquidez Londres/Europa — **NO** la apertura de Nueva York).
- **Órdenes Stop OCO bidireccionales:**
  - **Buy Stop** en `Highest(Close, 50)[1] + 10 pips`
  - **Sell Stop** en `Lowest(Close, 50)[1] - 10 pips`
  - Vigencia de ambas órdenes pendientes: `BarsValid = 90` barras (en `M15`/`M30` vence intradía; ajustar a término de sesión viernes antes de fin de semana).
- **Gestión de salida y riesgo:**
  - `StopLoss = BiggestRange(50)[1]` *(el rango máximo de vela de las últimas `50` barras)*
  - `ProfitTarget = BiggestRange(50)[1]` *(ratio `1:1` simétrico escalado dinámicamente al rango máximo reciente)*
  - `MoveSL2BE = 20 pips` (adaptable a `0.5 * ATR` al portar a índices/crudo).
  - **Alerta de código detectada en el `.sqx` original:** El bloque `IsFlat` del archivo `RangeBreakout.sqx` original pasa por error la variable `RangeEndingHour` (`13`) como argumento `magicNumber` en lugar de comprobar ambos mágicos `11111` y `22222`; en EdgeLab/MQL5 debe corregirse comprobando flat real por símbolo / mágicos.

### Pseudocódigo oficial (generado por SQX Build 145)
```text
//--------------------------------------------------------------------
// Pseudo Source Code of New strategy (RangeBreakout.sqx)
//   Generated by StrategyQuant X Build 145 for MetaTrader
//--------------------------------------------------------------------
int RangeEndingHour = 13;
int RangeEndingMinute = 0;
int BarsInRange = 50;
int StopOffsetInPips = 10;
int BarsValid = 90;
int MagicLong = 11111;
int MagicShort = 22222;

Main chart = Current Symbol / Current TF;

// Trading rule: Rule 1 (On Bar Open)
if ((((MarketPosition("Current", RangeEndingHour, "") is Flat)   // BUG en .sqx original: debería chequear MagicLong y MagicShort
   and (Pending Order("Current", MagicLong, 0, "") doesn't exist))
   and (Pending Order("Current", MagicShort, 0, "") doesn't exist))
   and (Bar Time[1] = GetTime(RangeEndingHour, RangeEndingMinute)))
{
    // Action #1
    Open Long order at (Highest(Main chart, BarsInRange, PRICE_CLOSE)[1] + ConvertToRealPips("Current", StopOffsetInPips)) Stop;
        Order valid for BarsValid bars;
        Size = 0.1; Duplicate trades = disabled; Replacing pending orders: allowed;
        Stop Loss at ConvertToPips("Current", BiggestRange(Main chart, BarsInRange)[1]);
        Profit target at ConvertToPips("Current", BiggestRange(Main chart, BarsInRange)[1]);
        Move SL to BE = 20pips;

    // Action #2
    Open Short order at (Lowest(Main chart, BarsInRange, PRICE_CLOSE)[1] - ConvertToRealPips("Current", StopOffsetInPips)) Stop;
        Order valid for BarsValid bars;
        Size = 0.1; Duplicate trades = disabled; Replacing pending orders: allowed;
        Stop Loss at ConvertToPips("Current", BiggestRange(Main chart, BarsInRange)[1]);
        Profit target at ConvertToPips("Current", BiggestRange(Main chart, BarsInRange)[1]);
        Move SL to BE = 20pips;
}
```

## Mecanismo y cómo podría refutarse

- **Mecanismo:** Captura la transición de liquidez cuando Europa ya estableció su rango matinal / Asia cerró, o antes del solapamiento europeo-americano, entrando únicamente si el precio rompe el extremo de `50` cierres por `StopOffset`. El `SL/TP` igual a `BiggestRange(50)` escala automáticamente el riesgo según la volatilidad reciente de velas grandes, reduciendo el impacto de comisiones y spreads.
- **Cómo refutarse en EdgeLab:** Si al evaluar `FDAX`, `6E`, `6B` y `CL` (`M15`/`H1`, costos futuros y cierre viernes): (1) genera expectancy `<= 0` por exceso de rupturas falsas en Europa (`6E`/`FDAX` son notoriamente revertidores en rangos matinales); (2) la sensibilidad a mover `RangeEndingHour` (`12:00`, `13:00`, `14:00`) o quitar `BE` destruye la curva.

## Hueco de diversificación

- **Sesión / Activo / Horizonte / Estilo:** Sesión **Europea / Londres (`13:00`)**, activos **DAX (`FDAX`), FX (`6E`/`6B`), Crudo (`CL`)**, horizonte **intradía–2 días**, estilo **ruptura OCO bidireccional de rango con tamaño de stop dinámico por `BiggestRange`**. Completamente separada de NY-open `NQ/ES` y del oro Londres ya descartado.
