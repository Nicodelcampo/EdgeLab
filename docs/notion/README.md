# docs/notion — catálogo de páginas

Apartado pedido el 17-ago-2026: todas las páginas de Notion del proyecto,
ordenadas por fecha, categorizadas, con actualidad y relevancia.

| archivo | rol |
|---|---|
| `CATALOG.md` | lectura humana |
| `catalog.json` | máquina / chequeos |
| `snapshots/YYYY-MM-DD/` | texto extraído de un export + sha256 del PDF |

Reglas: `docs/TRACEABILITY.md`. Punto de entrada: `docs/CURRENT.md`.

El UUID del filename de un PDF de export **no** es el ID vivo de la página.
El catálogo anota los dos cuando se conocen.
